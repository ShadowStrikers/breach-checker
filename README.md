# BreachWatch — Breach Email Checker

Check if your email appears in known data breaches, with an
optional AI-generated risk summary.

## Live Demo
[Try it here](https://shadowstrikers.github.io/breach-checker)

## What it does
Enter any email and BreachWatch checks it against real, live
breach records — including the breach name, date, exposed data
types, and record count.

## How it works
- Breach data comes from the free [XposedOrNot](https://xposedornot.com/) API, called directly from the browser
- AI risk summary (optional) is generated by the Google Gemini free API, using only a summary of the breach names/dates/data types — never the raw email
- No backend, no signup, no stored data

## Privacy
Email addresses are never stored or logged. The email is sent to
XposedOrNot to check for breaches, and — only if you add a Gemini
API key — a breach summary (not the raw email) is sent to Google's
Gemini API for the risk write-up.

## Limitations
Breach dates are year-only (as provided by the API), and severity
ratings are inferred client-side from record count and exposed
data sensitivity rather than sourced directly.
